# Sola Management Hub
- **Scope:** Greenfield React+Vite SPA — ички сервис хаб (iframe / open-in-tab). Auth йўқ.
- **Domain model:** Category + HubService; URL whitelist фақат `src/data/services.ts`.
- **Schema decisions:** DB йўқ (MVP). Статиқ TS каталог — роли келганда API+DB осон алмаштирилади. `embeddable` флаг сақланади.
- **Contracts:** клиент роутинг `/`, `/:categorySlug`, `/:categorySlug/:serviceId`. API йўқ.
- **Conventions:** components + data; inline SVG icons; CSS tokens in `index.css`.
- **Reversible vs not:** стек (React) ва URL каталог reversible; кейинги auth қўшиш учун алоҳида API керак бўлади.
- **Handoff:** роли/auth → backend employee; nginx prod → devops. UI вертикал срез тайёр.
